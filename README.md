# 📼 영상 레퍼런스함

영상 레퍼런스 수집 → 분류·검수 → 선정 공용 아카이브.

- 태그 2축: 욕구 / 타입 (앱에서 추가·삭제 가능)
- 상태: 📥수집됨 → ✅검수완료 → ⭐선정 / 🗑제외
- 인스타·유튜브·틱톡 카드 안 인라인 재생
- 데이터: `data/references.json` (앱이 GitHub API로 자동 커밋)
- 안드로이드: 사이트를 홈 화면에 설치하면 인스타 공유시트에 등록됨 (PWA share_target)
- 아이폰: 단축어로 `사이트주소?add=링크` 열기

등록·검수하려면 앱 ⚙️설정에 fine-grained PAT(이 저장소 Contents R/W)을 입력하세요.
