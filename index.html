📊 아카이브 현황

❓ 인스타에서 바로 넣는 법

① 기본: 링크 복사 (아이폰·안드로이드 공통)

  1. 인스타에서 영상 → 공유(비행기) → 링크 복사
  2. 이 사이트에서 ＋버튼 → 클립보드 링크가 자동으로 들어감 → 태그 찍고 저장

② 안드로이드: 공유시트에 앱처럼 등록 (추천)

  1. 크롬으로 이 사이트 접속 → 메뉴(⋮) → 홈 화면에 추가(앱 설치)
  2. 이후 인스타에서 공유 → "레퍼런스함" 선택하면 바로 등록창이 열림

③ 아이폰: 단축어로 공유시트에 등록

  1. 단축어 앱 → 새 단축어 → "공유 시트에 표시" 켜기 (입력: URL)
  2. 동작 추가: URL → 이 사이트 주소?add=단축어입력
  3. 동작 추가: URL 열기 → 저장 (이름: 레퍼런스함)
  4. 이후 인스타 공유 → 공유시트에서 레퍼런스함 탭

④ 텔레그램 봇 (아이폰·안드로이드 공통, 가장 편함)

  1. 인스타 공유 → Telegram → 레퍼런스 봇 채팅에 전송 (메모를 같이 쓰면 메모로 저장)
  2. 몇 분 안에 자동으로 레퍼런스함에 등록되고 봇이 ✅ 답장을 보냄 (봇 만들기는 저장소 README 참고)

팀원 초대

  1. 이 사이트 주소만 공유하면 보기는 바로 가능
  2. 등록·검수까지 하려면: ⚙️설정에 이름 + 저장소 + 토큰 입력 (토큰은 GitHub → Settings → Developer settings → Fine-grained token, 이 저장소 Contents 읽기/쓰기 권한만)

⚙️ 설정

저장소의 data/references.json에 자동 커밋됩니다. 토큰이 없으면 보기 전용 + 이 브라우저에만 저장돼요.
스마트 아카이브에 저장해둔 인스타/유튜브/틱톡 링크를 전부 가져옵니다. (중복·삭제했던 항목은 제외, 태그는 자동 매칭)
